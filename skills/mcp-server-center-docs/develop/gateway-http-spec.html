MCP 网关 HTTP 接入规范

作者: 飞超 · 更新时间: 2026-01-25

简介

本方案介绍了一个基于 MCP 的简化版本（下称 MCP-Lite），用于支持阿里集团内二方开发者自定义 MCP Server 的需求。二方开发者提供符合要求的 HTTP 接口（以下称为 MCP Provider），经过 Aone MCP 网关转换后，即可对外提供 MCP 协议。

系统上下文

参考 MCP Tool Message Flow，引入 MCP-Lite 后的流程如下：

阶段：创建 MCP 连接
User -> MCP Client: 添加 MCP Server，连接地址: mcp.aone.alibaba-inc...
MCP Client -> MCP Server Center: Connect
MCP Server Center -> MCP Client: HTTP 200, Content-Type: text/event-stream (保持 SSE 长连接)

阶段：列出 Tool
MCP Client -> MCP Server Center: MCP Message, method: "tools/list"
MCP Server Center -> MCP Provider: GET /tools/list
MCP Provider -> MCP Server Center: 工具列表元数据

阶段：调用 Tool
User -> MCP Client: 用户输入
MCP Client -> MCP Server Center: MCP Message, method: "tools/call", params: {"name": "get_weather"}
MCP Server Center -> MCP Provider: POST /tools/call {"name": "get_weather"}
MCP Provider -> MCP Server Center: 工具调用结果
MCP Server Center -> MCP Client: (使用 SSE 长连接返回结果)

MCP-Lite 协议

目前 MCP 中 Tools 相关的方法主要有以下三个：tools/list、tools/call、notifications/tools/list_changed。

在 MCP-Lite 中，我们用普通的 HTTP 接口代替 MCP 的 jsonrpc 接口。接口路径与 jsonrpc method 相同，数据格式与 MCP 尽量保持相同，方便后续复用 MCP 已有 SDK。

列出工具

请求

GET {endpoint}/tools/list

返回结果（与 MCP 标准一致）

{
  "tools": [
    {
      "name": "get_weather",
      "description": "Get current weather information for a location",
      "inputSchema": {
        "type": "object",
        "properties": {
          "location": {
            "type": "string",
            "description": "City name or zip code"
          }
        },
        "required": ["location"]
      }
    }
  ]
}

调用工具

请求

POST {endpoint}/tools/call
Content-Type: application/json

{
  "name": "get_weather",
  "arguments": {
    "location": "New York"
  },

  // 以下为 MCP-Lite 扩展字段
  "sessionKey": "SbWvOyeba1dTdSXa",
  "user": {
    "loginName": "feichao.sfc",
    "empId": "177403",
    "name": "飞超"
  },
  "state": "这里是 lite/init-state 接口返回的数据，可以为任意数据"
}

返回结果（与 MCP 标准一致）

{
  "content": [
    {
      "type": "text",
      "text": "Current weather in New York:\nTemperature: 72°F\nConditions: Partly cloudy"
    }
  ],
  "isError": false
}
