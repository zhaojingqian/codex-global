Java Aone MCP 研发手册

作者: 飞超 · 更新: 簪星 · 更新时间: 2026-05-13

mcp-lite-hsf-server-starter

特性

  • 参考 Spring AI 中 MCP Server Boot Starter 的设计，通过 @Tool 快速将已有方法转换为 MCP 工具
  • 兼容 Java 8，适配 Spring Boot 2 / 3
  • 应用启动时自动发布为 HSF 服务，无缝对接 Aone MCP

限制

  • 目前仅支持 tool 能力，暂不支持 prompts/resources 等其他 MCP 能力

引入 starter

引入 starter，建议使用最新版本。版本更新记录详见 版本更新记录

<dependency>
  <groupId>com.alibaba.mcp</groupId>
  <artifactId>mcp-lite-hsf-server-starter</artifactId>
  <version>1.2.2</version>
</dependency>

对于 kotlin 项目，需要额外引入 jackson-kotlin-module

<dependency>
  <groupId>com.fasterxml.jackson.module</groupId>
  <artifactId>jackson-module-kotlin</artifactId>
  <version>${jacksonVersion}</version>
</dependency>

如果项目中的 jackson 版本较低，可以在项目的 parent pom.xml 中指定 jackson 版本。jackson 版本需要大于等于 2.17.2

<dependencyManagement>
  <dependency>
    <groupId>com.fasterxml.jackson</groupId>
    <artifactId>jackson-bom</artifactId>
    <version>${jacksonVersion}</version>
    <type>pom</type>
    <scope>import</scope>
  </dependency>
</dependencyManagement>

配置 application.properties

# starter 会默认注册项目同名的 server 服务
project.name=your-project-name

# 配置 server 端的 timeout，默认 10000ms（1.3.0 起从 3000ms 调整为 10000ms）
mcp.hsf.server.timeout=10000

# 是否启动 server，默认开启
mcp.hsf.server.enable=true
完整的配置项列表，详见 com.alibaba.mcp.lite.boot.server.McpHsfProperties 的具体实现，IDEA 中会有自动提示

编译插件配置

配置编译插件，在编译时保留方法的参数元数据信息，帮助大模型更好的理解工具信息

<!-- java 构建插件配置-->
<plugin>
  <groupId>org.apache.maven.plugins</groupId>
  <artifactId>maven-compiler-plugin</artifactId>
  <configuration>
    <!-- 增加 compile 参数 -->
    <compilerArgument>-parameters</compilerArgument>

    <!-- 如果插件版本 >= 3.6.2，可使用以下配置 -->
    <parameters>true</parameters>
  </configuration>
</plugin>
<!-- kotlin 编译插件配置 -->
<plugin>
  <groupId>org.jetbrains.kotlin</groupId>
  <artifactId>kotlin-maven-plugin</artifactId>
  <configuration>
    <!-- 添加配置 -->
    <javaParameters>true</javaParameters>
  </configuration>
</plugin>

开发 tool

任意组件类 (@Controller/@Service/@Component/@Configuration…) 中的任意方法加上 @Tool 注释，即可完成工具的注册。

Java 代码示例

import com.alibaba.mcp.lite.tool.annotation.Tool;
import com.alibaba.mcp.lite.tool.annotation.ToolParam;
import com.fasterxml.jackson.annotation.JsonPropertyDescription;
import org.springframework.stereotype.Component;

@Component
public class McpServerDemo {
    @Tool.Group("生活服务")
    @Tool(name = "get_weather", description = "获取城市的天气预报")
    @Tool.Annotations.readOnlyHint(true)
    @Tool.Annotations.openWorldHint(true)
    public WeatherDetail getWeather(
        @ToolParam(description = "城市名称，例如杭州")
        String city,
        @ToolParam(description = "天气预报日期，例如 2025-09-28，默认为明天", required = false)
        String date
    ) {
        // 从 ToolContextHolder 获取当前 MCP 请求上下文，例如当前 BUC 用户或 headers
        String loginName = ToolContextHolder.getToolContext().getUser().getLoginName();
        logger.info("{} query weather of {}", loginName, city)

        // 根据 city 和 date 调用天气预报接口
        // 这里省略具体实现
        return new WeatherDetail();
    }
}

// file: WeatherDetail.java
// 定义工具返回结果类型，可使用 @JsonPropertyDescription 提供字段描述
@Data
class WeatherDetail {
    @JsonPropertyDescription("城市") private String city;
    @JsonPropertyDescription("日期") private String date;
    @JsonPropertyDescription("温度") private String temperature;
    @JsonPropertyDescription("湿度") private String humidity;
    @JsonPropertyDescription("天气状况") private String weatherCondition;
    @JsonPropertyDescription("数据更新时间") private LocalDateTime updateTime;
}

注解介绍

@Tool

@Tool 可以将一个 Java 方法转换为一个 MCP 工具，是目前定义工具的唯一方式。

  • 注解参数
    • name：工具名称，选填。默认使用 Java 方法名称作为工具名称，也可以改为其他任意名称
      • 工具名称：建议工具名称仅包含数字、英文字母、和 - _ 符号，避免包含空格或其他特殊字符
    • description：工具描述，选填。为了让大模型更好的理解和使用工具，建议添加详细的工具描述
      • 1.0.8 以前 description 字段必填，从 1.0.8 后改为选填
    • link：工具在线链接，选填。未开放能力，请勿使用
  • 工具的入参和返回值
    • 入参支持 @ToolParam 注解，用于添加参数描述和是否必填字段
    • 工具的入参和返回值采用 jackson 进行序列化和反序列化
      • 自定义类型请注意遵循相关约定，提供相关字段的 getter/setter 以及无参构造器
      • 自定义的 POJO（例如上面例子中的 WeatherDetail）请使用 jackson 提供的注解来添加字段信息
        • 例如使用 @JsonPropertyDescription("描述文本") 来添加字段描述，来帮助大模型更好地理解参数的作用
        • 在 Kotlin 中，请使用 @get:JsonPropertyDescription("描述文本")
  • 调用是否成功：
    • 当方法正常结束并返回时，表示工具调用成功
    • 若工具方法抛出任意异常，则表示调用失败，异常的 message 将被作为工具调用出错信息
      • MCP 工具调用结果中的 isError 字段将被设置为 true

@ToolParam

  • required：是否为必填参数，默认为 true，表示当前参数不能为空
  • description：参数描述，默认为空

@Tool.Group

指定工具分组。详见 Annotations & Output Schema

@Tool.Annotations

为 MCP 工具添加注解，支持 MCP 协议中的 标准注解。

详见 Annotations & Output Schema

调用工具上下文

通过 ToolContextHolder.getToolContext() 可以获得当前 MCP 请求的上下文，上下文中包含 sessionKey（MCP 会话标识）、user（当前用户信息）、headers、queryParams 等字段。

import com.alibaba.mcp.lite.spec.LiteMcpSchema;
import com.alibaba.mcp.lite.tool.ToolContext;
import com.alibaba.mcp.lite.tool.ToolContextHolder;
import com.alibaba.mcp.lite.tool.annotation.Tool;
import org.springframework.stereotype.Component;

import java.util.Map;

@Component
public class McpServerDemo {
    @Tool(name = "hello", description = "打个招呼")
    public String hello() {
        ToolContext context = ToolContextHolder.getToolContext();
        LiteMcpSchema.User user = context.getUser();

        String nickName = user.getNickName(); // 用户的花名或真名
        String empId = user.getEmpId(); // 用户工号（注意工号前面没有 0）
        String loginName = user.getLoginName(); // BUC 域账号

        Map<String, String> headers = context.getHeaders();
        Map<String, String> queryParams = context.getQueryParams();

        return "你好，" + nickName + "(" + empId + ")";
    }
}

调试

本地/日常环境 应用启动之后，starter 会自动发布 HSF 服务，你可以通过 https://mcp.taobao.net/proxy/hsf/{project.name} 这个 SSE 连接地址进行调试。你可以把这个地址放到 MCP Inspector 中，也可以复制到任意 MCP 客户端（例如 Cursor）中进行体验。

注意：调试开发时，你需要在链接后面加上个人 Token，所以完整的链接格式为：

https://mcp.taobao.net/proxy/hsf/<project.name>?private_token=xxxx

关于 proxy 的更多信息详见：日常环境调试代理

预发调试

你需要先将服务注册到 Aone MCP 市场，然后通过 Aone 开放平台 生成预发链接进行调试。

注册、发布与上架

注册、发布与上架是 3 个不同的操作，其含义与操作路径如下。

注册

注册 指的是将你的 Java 应用 注册 到 Aone 开放平台中生成一个 MCP Server（该 Server 默认情况下仅你可见）
  • 注册到 Aone MCP 市场，详情请移步 注册链接

发布

发布 是指的是将 Java 应用（以及背后的 HSF 服务）发布 到生产环境，并将 MCP 工具元数据 发布 到 MCP 网关的生产环境
  • 按常规流程发布你的 Java 应用到生产环境
  • 前往 MCP Server 管理页面，进入 "发布" Tab，按流程完成工具发布

上架

上架 是指将你的 MCP Server（默认只有你可见）上架 到 Aone MCP 市场，使得其他用户通过 MCP 市场（浏览或搜索）发现你的 MCP Server。
  • 首次完成线上发布时，可直接进行上架。
    • 上架前请检查开放范围，建议一开始开放给你所在团队，进行内部试用。
  • 其他情况下，请前往 MCP Server "设置" 页面进行上架操作

进阶用法

CallTool 拦截器

你可以实现 ToolInterceptor 接口来添加工具调用的拦截器。在拦截器中，你可以对原始请求和响应结果进行自定义的处理。

import com.alibaba.mcp.lite.spec.LiteMcpSchema;
import com.alibaba.mcp.lite.tool.ToolInterceptor;
import org.springframework.stereotype.Component;

@Component
public class ToolInterceptorA implements ToolInterceptor {
    @Override
    public void preHandle(LiteMcpSchema.CallToolRequest request) throws Exception {
        // your process here, invoked before the actual tool call
    }

    @Override
    public void postHandle(LiteMcpSchema.CallToolRequest request, LiteMcpSchema.CallToolResult result) throws Exception {
        // your process here, invoked after the tool call has been completed
    }
}

配置多个拦截器时，可通过 @Order 指定拦截器的顺序：

@Component
@Order(1)
public class InterceptorA implements ToolInterceptor { }

@Component
@Order(2)
public class InterceptorB implements ToolInterceptor { }

例如，上面配置了 A（order=1）和 B（order=2）两个拦截器，相关方法的执行顺序为：

A.preHandle -> B.preHandle -> tool call -> B.postHandle -> A.postHandle

配置 HSF 调用方白名单

默认情况下，mcp-lite-hsf-server-starter 发布的 HSF 服务仅支持从 Aone MCP 网关（应用名：mcp-server-center）进行调用。你可以使用下面的配置调整调用方白名单：

# 支持配置授权 mcp-server-center 以外的调用方应用
# 例如配置 hsfops，方便从 HSF 控制台进行调试
mcp.hsf.server.authorized-clients[0]=hsfops

[不建议使用] HSF 多单元注册

不建议使用 HSF 多单元注册，请使用 HSF 多套环境适配方案 代替。

目前 Aone MCP 网关仅部署在中心预发 / 中心线上环境，如果你的应用机器部署在其他环境，需要配置 HSF 多单元注册，配置方式如下：

# application-staging.properties
# 预发注册到 pre
mcp.hsf.server.config-centers[0]=pre

# application-production.properties
# 线上注册到 sh
mcp.hsf.server.config-centers[0]=sh
