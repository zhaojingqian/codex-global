Annotations & Output Schema

作者: 飞超 · 更新时间: 2026-01-25

我们从 mcp-lite-hsf-server-starter 开始支持 MCP 协议中的 Tool Annotations 和 Output Schema。

工具注解

MCP 标准注解

通过 @Tool.Annotations.readOnlyHint(true) 对工具进行打标，支持 MCP 工具的标准注解。

@Component
class MyMcpServer {
    @Tool(name = "my_tool", description = "工具描述、工具描述")
    @Tool.Annotations.readOnlyHint(true)
    @Tool.Annotations.destructiveHint(false)
    @Tool.Annotations.idempotentHint(true)
    public String myTool() {
        // 省略具体实现
    }
}
在 mcp-lite-hsf-server-starter 中，所有注解的默认值均为 null；当开发者在代码中添加相关注解时，注解的值才会出现在 tool.annotations 对象中。

Aone 扩展注解：group

@Component
@Tool.Group("class-level")
class MyMcpServer {
    @Tool(name = "my_tool", description = "工具描述、工具描述")
    @Tool.Group("method-level")
    public String myTool() {
        // 省略具体实现
    }
}

你可以使用 @Tool.Group 在类或方法上添加分组标签，Aone 开放平台页面中将分组展示工具。

  • 方法上的注解优先级高于类上的注解
  • @Tool.Group 仅用于优化前端页面展示，不影响工具行为

Aone 扩展注解：link

该能力当前暂未开放，需 Aone 开放平台侧按 MCP Server 的粒度主动进行开通，如有需求请联系 @史飞超(飞超)。

在 @Tool(...) 注解中，填写 link = "https://mcp.alibaba-inc.com/tools/{server}/{tool}" 格式的链接

@Component
public class MyMcpServer {
    @Tool(
      // 只需要按格式填写 link 参数，不用填写其他参数
      link = "https://mcp.alibaba-inc.com/tools/{server}/{tool}"
    )
    public String myToolCallback(String arg1, String arg2) {
        // Tool 处理逻辑
    }
}

设置 link 参数后，工具的描述将被托管至 Aone 开放平台，代码中可省略 @Tool 的 name 和 description 参数：

  • name 将从 link 中自动解析
  • description 将维护在 Aone 开放平台上
    • 当开放平台中没有对应工具的描述时，代码中的 description 将作为兜底值

此时，开发者在浏览器中打开 https://mcp.alibaba-inc.com/tools/{server}/{tool} 链接，浏览器会自动跳转到工具描述的编辑页面，效果如下：

Output Schema

我们发现 Output Schema 在实际使用过程中，MCP SDK 对 structured output 校验非常严格，容易导致工具调用失败。

你可以参考下方 "自定义 Output Schema 输出位置"，将 Output Schema 输出到其他位置，避免校验导致工具调用失败。

outputSchema 需主动开启，在 application.properties 添加以下配置：

mcp.hsf.server.output-schema=true

注意事项：

  • 开启后，mcp-lite-hsf-server-starter 会通过反射获取 @Tool 方法的返回值类型，并生成相应的 JSON Schema 作为 tool.outputSchema
  • 按照 MCP 规范，开启 output schema 后，工具调用结果中必须包含 structuredContent 字段，SDK 会将 @Tool 方法返回值作为 structuredContent 内容
    • 延续开源 Java MCP SDK 的行为，Aone 提供的 MCP SDK 也同样使用 Jackson 序列化
    • 请确保你的工具方法返回值可以被 Jackson 进行序列化
  • 由于 Java MCP SDK 和 MCP 协议限制，只有当工具的返回结果类型是 "Object Like" 时，工具才会开启 outputSchema
    • 一般来说，当工具返回结果类型是 Map 或自定义 POJO 类型时，该工具将开启 outputSchema
    • 如果工具返回结果类型是 String、Integer、Boolean 或其他非 Object Like 类型，那么该工具不会开启 outputSchema
      • "Array Like" 的类型（例如数组、列表）目前不会生成 outputSchema
  • 请使用 @JsonPropertyDescription("描述文本") 来添加字段描述
    • Kotlin 中请使用 @get:JsonPropertyDescription("描述文本")

自定义 Output Schema 输出位置

支持指定 Output Schema 的输出位置，mcp.hsf.server.output-schema 可选值如下：

  • standard/true：输出到标准字段 tool.outputSchema，同步启用 structuredContent
  • description：追加到 tool.description
  • annotations：写入一个自定义的工具注解中 tool.annotations["com.alibaba.mcp/outputSchema"]
  • disabled/false：关闭（默认值）

Kotlin 参考代码

import com.alibaba.mcp.lite.tool.ToolContextHolder
import com.alibaba.mcp.lite.tool.annotation.Tool
import com.fasterxml.jackson.annotation.JsonPropertyDescription
import org.springframework.stereotype.Component

@Component
class McpServerExample {
    @Tool.Group("default-group")
    @Tool(name = "hello", description = "打个招呼，工具会根据当前用户返回打招呼的信息")
    @Tool.Annotations.readOnlyHint(true)
    @Tool.Annotations.destructiveHint(false)
    fun hello(): String {
        val nickName = ToolContextHolder.getToolContext().user.nickName
        return "你好，$nickName"
    }

    data class ToolResult(
        @get:JsonPropertyDescription("Description of ToolResult.foo")
        val foo: String,
        @get:JsonPropertyDescription("Description of ToolResult.bar")
        val bar: Int,
    )

    @Tool(link = "https://mcp.alibaba-inc.com/tools/aone-smart-tools/tool_with_dynamic_description")
    @Tool.Annotations.readOnlyHint(true)
    @Tool.Annotations.destructiveHint(false)
    fun dynamicToolDescription(): ToolResult {
        return ToolResult("foo", 1)
    }
}
