网关默认下发请求头

作者: 飞超 · 更新时间: 2026-05-21

工具提供方从下面 3 个保留请求头中获取本次工具调用的来源信息。三个头由网关基于已通过鉴权的身份注入，客户端或服务端 headers 配置均无法伪造。

Header 来源 示例 何时缺失
Mcp-Caller-System 调用方系统名（来自 Normandy AuthSdk 携带的可信系统身份） aone-open-platform、starops-agents、amap-llm-biz-app-gateway 不经 Normandy 接入时缺失
Mcp-Agent-Id Agent 唯一 ID agent-wukong、agent-qoderwork 调用方不是 Agent 时缺失
Mcp-Client-Name 调用方客户端可读名称 mcp-host:claude-code、mcp-host:unknown、aone-open-agent 无客户端信息时缺失

三个 header 可同时出现（如 Agent 通过 OAuth Client 调用、来自某 Aone 系统的 Agent 调用等）。
