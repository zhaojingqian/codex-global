编码开发

开发工具

我们使用官方的 MCP SDK 来实现工具（完整文档见 Python SDK 的 GitHub 仓库，本文只列出一些基础的示例）

# server.py
from mcp.server.fastmcp import FastMCP

# Create an MCP server
mcp = FastMCP("Demo")

# Add an addition tool
@mcp.tool()
def add(a: int, b: int) -> int:
    """Add two numbers"""
    return a + b

# Add a dynamic greeting resource
@mcp.resource("greeting://{name}")
def get_greeting(name: str) -> str:
    """Get a personalized greeting"""
    return f"Hello, {name}!"

参数定义

from pydantic import Field, BaseModel

# 简单参数场景
@mcp.tool()
async def tool_add(
    a: int = Field(description="The second number", default=1),
    b: int = Field(description="The second number", default=1),
) -> int:
    """Add two numbers"""
    lite_ctx = lite_ctx_vars.get()
    print("lite_ctx:", lite_ctx)
    return a + b

# 复杂参数场景
class ComplexObj(BaseModel):
    name: str = Field(description="Your name")

@mcp.tool()
def tool_complex_exam(
    obj: ComplexObj = Field(description="Complex Object"),
) -> str:
    """Get a personalized greeting"""
    return f"Hello, {obj.name}!"
  • 借助 Pydantic Field 进行定义，详细用法可参考文档：https://docs.pydantic.dev/latest/concepts/fields/

连接 HTTP 端点

实现工具后，你需要创建两个 HTTP 端点，将工具暴露出来：

from fastapi import FastAPI, Request

# 省略工具定义相关代码

app = FastAPI()

@app.get("/tools/list")
async def list_tools():
    tools = await mcp.list_tools()
    return {"tools": tools}

@app.post("/tools/call")
async def call_tool(request: Request):
    try:
        data = await request.json()
        name = data.get("name")
        arguments = data.get("arguments", {})

        # 设置上下文，在工具回调方法中可通过 lite_ctx_vars.get() 进行获取
        lite_ctx_vars.set(data)

        content = await mcp.call_tool(name, arguments)
        return {"content": content, "isError": False}
    except Exception as e:
        traceback.print_exc()
        return {"content": [{"type": "text", "text": str(e)}], "isError": True}

这段代码创建了两个 HTTP 端点，符合 MCP 网关 HTTP 接入规范：

  • /tools/list：GET 请求，用于列出所有可用的工具
  • /tools/call：POST 请求，用于调用特定的工具
使用不同的 Web 框架时，GET /tools/list 和 POST /tools/call 端点的定义方式不同。如果你正在使用 Flask 或其他 Web 框架，请调整相关代码。

调试

本地使用 MCP Proxy 代理

执行 uv run server.py 在本地启动应用后，打开下面的地址（注意换成你本地的 IP，一般使用 30 开头，只需要替换这个 IP 地址即可）：

https://mcp.taobao.net/proxy/http/30.166.1.73:9000

这是一个日常/办公网环境可用的 MCP SSE 连接地址（这里需要注意，中间是 http，而不是 https）。你可以使用 MCP Inspector 或其他 MCP Client 来进行调试

使用 MCP Inspector 进行调试

https://mcp.alibaba-inc.com/inspector

预发调试

将你的 FaaS 应用发布至预发环境，获得一个预发域名，例如 mcp-lite-python-demo.pre-fn.alibaba-inc.com（如果是已有应用，此处换成已有域名）

你可以继续使用 https://mcp.taobao.net/proxy 进行调试，注意预发的时候要用 /proxy/https，例如：

https://mcp.taobao.net/proxy/https/mcp-lite-python-demo.pre-fn.alibaba-inc.com

你也可以将 MCP Server 注册到开放市场，并通过开放市场生成预发的 SSE 地址，例如：

http://pre-mcp.alibaba-inc.com/my_mcp/sse?secretKey=xxxxxx

进阶技巧

传递自定义的上下文

你可以使用 contextvars.ContextVar(...) 来传递自定义的上下文，在工具回调中获取当前 HTTP 请求中的任意数据：

# 定义上下文
import contextvars

lite_ctx_vars = contextvars.ContextVar("lite_ctx_vars")

# 设置上下文
@app.post("/tools/call")
async def call_tool(request: Request):
    try:
        data = await request.json()
        name = data.get("name")
        arguments = data.get("arguments", {})
        # 除了 name / arguments，data 中还包含了 sessionKey/user 等信息
        # 设置上下文，在工具回调方法中可通过 lite_ctx_vars.get() 进行获取
        lite_ctx_vars.set(data)
        # ...省略其他代码...

# 读取上下文中的数据
@mcp.tool()
async def tool_callback(arg1, arg2) -> int:
    lite_ctx = lite_ctx_vars.get()
    # ...省略其他代码...
