Aone FaaS MCP 研发手册

作者: 飞超 · 更新时间: 2026-01-25
本文介绍如何通过 Aone FaaS 提供 HTTP 接口接入，当前为 Node.js 版本，Python 版本请移步 Python Aone MCP 研发手册
如果想要通过已有的 应用/FaaS 提供 HTTP 接口接入，请移步 MCP 网关 HTTP 接入规范

创建应用

  • 前往 https://cd.faas.alibaba-inc.com/unite/micro/create
  • 选择 接口服务 > Nodejs Aone MCP，点击下一步
  • 填写应用仓库，任选一个租户，填写函数应用名
    • 函数应用名建议用 xxx-mcp 的格式

已有 Node.js 应用

如果已有 Node.js 应用，可以在项目中引入 @ali/mcp-lite，而不必新建 FaaS 应用。

{
  "dependencies": {
    "@ali/mcp-lite": "^1.12.0",
    "zod": "^3.25.64"
  }
}
@ali/mcp-lite 的最新版本请访问 Ali NPM 获取：https://anpm.alibaba-inc.com/package/@ali/mcp-lite

编码开发

开发工具

引入必要的依赖后，你需要创建一个 McpLiteServer 实例，并通过 server.tool() 方法注册工具。

import { Body, Headers, Provide, ServerlessTrigger, ServerlessTriggerType } from '@midwayjs/core';
import { EchoTransport, getLiteExtra, McpLiteCallToolRequest, McpLiteServer } from '@ali/mcp-lite';
import * as z from 'zod';

// 注意此时使用 McpLiteServer 代替标准的 McpServer
// 两者用法相同，详见 MCP 官方文档
const server = new McpLiteServer({ name: 'test', version: '1.0.0' });

// 通过 server.tool() 定义一个 MCP 工具
server.tool(
  'tool_name',
  'Tool description',
  {
    arg1: z.string().optional().describe('Argument description'),
  },
  async (args) => {
    const arg1 = args.arg1;
    const extra = getLiteExtra(args);

    // YOUR TOOL IMPLEMENTATION

    return {
      content: [{ type: 'text', text: 'hello' }],
      isError: false,
    };
  },
);
// 更多工具注册 server.tool(...)

工具入参与返回值

工具的入参需要使用 zod 进行定义。

工具函数应该返回符合 MCP 规范的响应对象：

{
  content: [
    {
      type: 'text',
      text: '返回的文本内容'
    }
  ],
  isError: false
}

如果需要返回错误，可以设置 isError: true 并提供错误信息。

示例：按关键字搜索 NPM 包

server.tool(
  'search_package_by_keyword',
  '根据关键字搜索 Ali NPM 中的包',
  { q: z.string().describe('查询关键字') },
  async (args) => {
    const { q } = args;
    const response = await makeHttpRequest(
      `https://anpx.alibaba-inc.com/open/search?q=${encodeURIComponent(q)}`,
      { dataType: 'json' },
    );
    return {
      content: [{ type: 'text', text: JSON.stringify(response.data) }],
      isError: false,
    };
  },
);

配置 Transport 并连接 HTTP 端点

注册完工具后，需要配置 Transport，这里必须使用 EchoTransport

import { EchoTransport } from '@ali/mcp-lite';

server.connect(new EchoTransport());

同时，你需要创建两个 HTTP 端点，并按照以下方式处理 HTTP 请求：

@Provide()
export class StandardStyleLiteMcpServer {
  @ServerlessTrigger(ServerlessTriggerType.HTTP, {
    path: '/tools/list',
    method: 'get',
  })
  async listTools() {
    return await server.listTools();
  }

  @ServerlessTrigger(ServerlessTriggerType.HTTP, {
    path: '/tools/call',
    method: 'post',
  })
  async callTool(@Body() body: McpLiteCallToolRequest, @Headers headers: Headers) {
    return await server.callTool(body, { timeout: 60_000 });
  }
}

这段代码创建了两个 HTTP 端点，符合 MCP 网关 HTTP 接入规范：

  • /tools/list：GET 请求，用于列出所有可用的工具
  • /tools/call：POST 请求，用于调用特定的工具
使用不同的 Web 框架时，GET /tools/list 和 POST /tools/call 端点的定义方式不同，请根据你正在使用的 Web 框架调整相应的代码。

下面是使用 Express 作为 Web 框架的示例代码：

import * as express from 'express';
import { z } from 'zod';
import { EchoTransport, McpLiteServer } from '@ali/mcp-lite';

const server = new McpLiteServer({ name: 'test', version: '1.0.0' });

// server.tool(tool1);
// server.tool(tool2);

server.connect(new EchoTransport());

const app = express();
app.use(express.json());

app.get('/tools/list', async (req, res) => {
  res.json(await server.listTools());
});

app.post('/tools/call', async (req, res) => {
  res.json(await server.callTool(req.body, { timeout: 60000 }));
});

app.listen(8001, () => {
  console.log('server is running on 8001');
});

调试

本地使用 MCP Proxy 代理

执行 tnpm install 安装项目依赖后，运行 tnpm run dev，然后打开下面的地址（注意换成你本地的 IP，一般使用 30 开头，只需要替换这个 IP 地址即可）：

https://mcp.taobao.net/proxy/http/30.166.1.73:7001

这是一个日常/办公网环境可用的 MCP SSE 连接地址，这里需要注意，前面一定是 https 的，你可以使用 MCP Inspector 或其他 MCP Client 来进行调试

使用 MCP Inspector 进行调试

https://mcp.alibaba-inc.com/inspector

预发调试

将你的 FaaS 应用发布至预发环境，获得一个预发域名，例如 aone-base-mcp.pre-fn.alibaba-inc.com。（如果是已有的 Node.js 应用，此处换成自定义的域名）

你可以继续使用 https://mcp.taobao.net/proxy 进行调试，注意预发的时候要用 /proxy/https，例如：

https://mcp.taobao.net/proxy/https/test-mcp-server-nodejs.pre-fn.alibaba-inc.com

你也可以将 MCP Server 注册到开放市场，并通过开放市场生成预发的 SSE 地址，例如：

http://pre-mcp.alibaba-inc.com/my_mcp/sse

进阶技巧

获取上下文

部分字段依赖新版本的 SDK，请注意升级项目中的 @ali/mcp-lite 版本

通过 getLiteExtra() 可以在工具回调中获取调用上下文：

server.tool(
  'show_call_tool_request',
  '展示调用工具请求',
  {
    arg: z.any().optional(),
  },
  async (args) => {
    const extra = getLiteExtra(args);
    // const { sessionKey, user, data, query } = extra;

    const text = JSON.stringify({ arg: args.arg, extra });
    return {
      content: [{ type: 'text', text: text }],
      isError: false,
    };
  },
);

这可以帮助你获取：

  • sessionKey：会话唯一标识
  • user：当前 BUC 用户信息
    • user.loginName：用户域账号（邮箱前缀）
    • user.empId：员工工号（注意工号前不带 0）
  • query：客户端连接 SSE 时的请求参数
    • 可用于透传自定义的业务字段，query 中不包含 secretKey、private_token 等敏感字段
    • 示例：客户端通过 https://mcp.alibaba-inc.com/test/sse?foo=bar 进行连接时，在 MCP Server 侧可以获取到 { "foo": "bar" } 这样一个 query 对象

传递自定义的上下文

你可以使用 Node.js 标准库中的 AsyncLocalStorage 来传递自定义的上下文，满足更加灵活的消费场景：

import { AsyncLocalStorage } from 'node:async_hooks';

const asyncLocalStorage = new AsyncLocalStorage();

const server = new McpLiteServer({ name: 'mcp-test', version: '1.0.0' });

server.tool(
  'name',
  'description',
  {
    arg: z.string(),
  },
  async (args) => {
    // 获取自定义的上下文
    const ctx = asyncLocalStorage.getStore();

    // 剩余工具逻辑...
  },
);

// 调整 '/tools/call' 路由
app.post('/tools/call', async (req, res) => {
  // ctx 可以是任意自定义数据
  // 你也可以将 ctx 设置为 req.body，这样工具回调中可以获取到本次 POST 请求的所有数据
  const ctx = {};
  return await asyncLocalStorage.run(ctx, async () => {
    res.json(await server.callTool(req.body, { timeout: 60000 }));
  });
});

使用个人账号进行调试

使用 http://mcp.taobao.net/proxy/http/ 代理调试开发时，getLiteExtra 获取得到的是 匿名用户的信息，你可以在链接后面加上个人 Token，切换到个人账号调试，链接格式为：

http://mcp.taobao.net/proxy/http/30.166.1.73:7001?private_token=xxxxxxxxxxx

注意：当 MCP Server 发布到预发/正式环境时，getLiteExtra 总是可以获取到某个 BUC 用户的信息。

对接 BUC 免登

详见文档：BUC 应用免登

注意事项：

  • HTTP 接入类型（例如 Node.js Aone FaaS 应用）：
    • 下游可通过 BUC-SSO-TICKET 请求头获取 Ticket
    • 若 mcp.buc-sso-ticket.include-in-query=true（该选项默认为 true），则 ticket 会同时放在 SSO_TICKET 查询参数上
    • 注意：网关请求 tools/list 接口时，是没有用户身份的，ticket 仅在调用 tools/call 接口才会提供。
