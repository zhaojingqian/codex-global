调整 MCP Server 的选项

作者: 飞超 · 更新时间: 2026-01-25

完成 MCP Server 注册后，你可以按照本文修改 MCP Server 设置，例如调整工具调用超时时间、或是附加自定义的 HTTP 请求头。

操作路径

MCP Server 详情页 → 设置 → 选项

注意事项

  • 选项分为预发和线上环境，不同环境需单独配置
  • 选项采用 properties 文件格式，编辑前请对该格式有一定了解
# 建议统一使用 kebab-case
mcp.max-body-size=4MB

# 不推荐使用 camelCase（虽然 Spring 解析 properties 文件时也支持）
mcp.maxBodySize=4MB

# 不建议行首包含空格
   mcp.max-body-size=4MB

配置一览

当前文档仅列出常用的选项，完整列表请在开放平台中点击 "查看选项列表" 按钮

mcp.max-body-size

单次工具调用返回结果的最大体积，默认为 4MB。

mcp.tool-call-timeout

  • 单次工具调用的超时时间。
  • 该选项留空表示使用 "MCP 网关内置超时时间" 的默认值，默认为 60s。
  • 可修改为自定义时间，例如 90s 或 10m，最大可设置为 1h。

mcp.headers

默认情况下，网关通过 HTTP/HSF 调用 MCP Tool Provider 时，仅传递部分必要的请求头，例如 EagleEye-TraceId、Authorization。为了方便开发者根据业务需求灵活传递请求头，网关支持通过 mcp.headers 配置自定义请求头。

详见 网关默认下发请求头

mcp.allow-user-list

指定允许使用该 MCP Server 的 BUC 用户列表。添加用户工号后，即使用户不在当前 MCP Server 开放范围内，该用户也依旧可以调用该 MCP Server 中的工具。

多个用户工号使用英文逗号分隔，例如：

mcp.allow-user-list=177403,WORKER_1735026162968,287523

hsf.app-group

指定 HSF Service 对应的 Aone 应用分组。详见 HSF 多套环境适配方案

hsf.route

自定义 HSF 路由规则，允许开发者动态指定应用分组，同时支持 HSF 跨单元调用。详见 HSF 多套环境适配方案

mcp.buc-sso-ticket

BUC 免登配置，详见 BUC 应用免登

mcp.trust-caller-systems

信任的调用来源系统列表，详见 系统间授权
