使用流程

介绍如何将已有的 MCP Server 中的工具，编排为一个新的工具集

平台右上角 "创建 MCP 工具集"

填写基础信息后提交：

选择"工具"，即可管理工具集中的工具

  • 可选工具范围：当前工具集公开范围内可用的 MCP 工具
  • 仅支持 MCP-Lite 网关接入的工具，暂不支持 Zetta 网关（Interface Transform）接入的工具
  • 其它功能和 MCP 服务相同（如 SSE 链接、基础设置、说明信息、服务上架等）
