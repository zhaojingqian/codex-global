调试与运维

作者: 飞超 · 更新时间: 2026-01-25

运维入口

MCP 负责人可以在管理页面上看到 "沙箱运维" 面板。该面板会展示活跃的沙箱分组，并提供 WebUI、WebShell 入口：

WebUI

WebUI 功能：

  • 查看日志（右上角）
  • 查看活跃的子进程列表及其日志（表格）
  • 手动启动子进程，然后进行 inspect

WebShell

小提示：

  • 登录容器后，可通过 sudo su 切换到 root 用户
  • 子进程工作目录：/root/mcp/sessions/{sessionKey}/
    • 相关日志文件也会放在该目录下
  • supervisor 进程日志文件：/root/mcp/mcp-sandbox-cli.log
