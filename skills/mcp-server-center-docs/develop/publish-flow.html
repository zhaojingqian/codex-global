MCP 发布流程

作者: 月侠 · 更新: 飞超 · 更新时间: 2026-01-25

背景

为了保证 MCP 的质量和安全性，我们对 MCP 的发布流程增加了一些规范。

变动内容

移除了原 MCP 上架的流程，改为 MCP 发布，包括以下几点：

1. 修改 MCP 源服务代码部署后，不会立即生效，需要到 MCP 详情 -> 发布页点击发布后生效

（源服务指的是提供 HTTP / HSF / SSE 接口的服务）

2. 发布页会展示当前 MCP 源服务预发修改的内容，先发布预发再发布线上

3. 发布线上前，需要源服务代码先部署上线，然后提交审批发布，首次发布线上后，MCP 会自动上架

4. 后续的每次 MCP 修改，都要经过这个流程才能上线生效

5. open_api_transform 类型的 MCP 可以在预发发布时直接修改 API 转换 MCP 的规则，修改后同样需要发布预发、发布线上

后续规划

在「发布预发」和「发布线上」之间，我们会加上「质量检测」的阶段，检测通过后才能进入下一阶段，用于自动检测并拦截有质量/安全问题的 MCP。
