版本更新记录

mcp-lite-hsf-server-starter · 更新时间: 2026-05-28
Maven 坐标：com.alibaba.mcp:mcp-lite-hsf-server-starter
最新版本请访问 ArtLab 查询。

1.3.0 即将发布

预计 2026-06
  • 新功能 单应用多 MCP Server — 通过声明多个 HsfMcpServerRegistration Bean，在一个应用中注册多个独立的 MCP Server，不声明时向后兼容。已上线应用切换前请阅读迁移指南。详细文档

1.2.0

2026-01
  • 新功能 Tool Annotations — 支持 MCP 标准工具注解（readOnlyHint、destructiveHint 等）。详细文档
  • 新功能 Output Schema — 通过 mcp.hsf.server.output-schema 开启，支持 standard、description、annotations 三种输出位置。详细文档
  • 新功能 @Tool.Group — 类或方法级分组标签，Aone 开放平台按分组展示工具
  • 新功能 @Tool link — 将工具描述托管到 Aone 开放平台

1.1.0

2025-09
  • 新功能 ToolInterceptor — 工具调用前置/后置拦截器，支持 @Order 排序。详细文档
  • 新功能 ToolContextHolder — 获取当前 MCP 请求上下文（user、headers、queryParams 等）。详细文档
  • 新功能 HSF 调用方白名单 — mcp.hsf.server.authorized-clients 配置

1.0.8

2025-04
  • 新功能 HSF 多套环境适配 — use-app-group-as-name 按应用分组发布不同 HSF 服务。详细文档
  • 优化 @Tool description 改为选填

1.0.0

2025-01
  • 新功能 初始版本 — @Tool / @ToolParam 注解定义 MCP 工具，启动时自动发布 HSF 服务。兼容 Java 8，适配 Spring Boot 2 / 3。详细文档
