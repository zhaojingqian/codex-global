MCP Client 注册流程

作者: 簪星 · 更新时间: 2026-05-15

前言

  • 你的 MCP Client 需要被使用在 特定的系统或 Aone 应用中
  • 每个 MCP Client 唯一归属于一个接入身份
  • 接入身份是 Aone 开放平台面向使用者的身份证明，接入身份必须与 Aone 应用身份关联（接入身份创建后会自动绑定关联的 Aone 应用，并且同步应用成员，所有成员都可以看见并使用此接入身份）
  • 出于 MCP 调用来源管控需求，MCP Client 自身也需要与被使用的 Aone 应用唯一关联，且 每个 Aone 应用只能创建一个 MCP Client
  • 接入身份与 MCP Client 关联的 Aone 应用最好相同（也可以不同，如果在你的研发组织或业务系统中，是一个基础应用下游管理了许多实际业务应用，且不希望组织内有过多的接入身份，那么接入身份可以是这个基础应用，MCP Client 是实际业务应用，归属于基础应用的接入身份下）
  • 请使用 Aone 开放平台的正式环境页面进行操作，不要用预发！！！

Step1: 选择/创建接入身份

  • 登录至 Aone 开放平台：https://open.aone.alibaba-inc.com
  • Aone 应用已有接入身份时，点击 导航栏接入管理，选择接入身份：https://open.aone.alibaba-inc.com/console/identity
  • Aone 应用尚无接入身份时，点击 右上角快捷入口，创建接入身份：
  • 选择你使用这个 MCP Client 的 Aone 应用来创建

Step2: 注册 MCP Client

  • 选择/创建好接入身份后，点击进入身份管理页，左侧边栏切换到 MCP 客户端管理
  • 点击 添加 MCP 客户端
  • 进入 MCP Client 注册表单，填写信息
  • 选择你使用这个 MCP Client 的 Aone 应用，Aone 应用名将作为你的客户端编码（唯一标识，不可重复不可修改）
  • 正式/预发回调地址：填写你的 Aone 应用统一接入部署域名地址，用于接收用户授权后的回调信息
    • 此处有疑问请先仔细阅读 OAuth2.1协议文档、MCP 授权协议文档 和 静态客户端接入指南
    • 回调地址的作用：在 OAuth 授权流程中，你需要构造一个授权链接，用户在浏览器打开授权链接后，会根据不同的 MCP Server 的配置，重定向至相应的 授权服务器（例如 BUC OAuth2），用户登录 授权服务器并完成身份认证，重定向至 MCP Client 回调地址并带上 code 和 state 参数
    • 回调地址后续支持编辑
  • 填写好注册表单后，点击 添加客户端（发起审批）
    • 审批流程：接入身份 Owner -> Aone 应用 Owner -> 开放平台系统管理员

Step3: 使用 MCP Client

  • 注册审批通过前，客户端 未激活，详情页会展示 BPMS 审批链接，支持撤销后重新编辑并发起审批
  • 注册审批通过后，为会为客户端颁发密钥，刷新详情页，客户端更新为 已激活 状态即可使用
  • 编辑入口在基本信息卡片的右上角
  • 客户端编码即为你注册时选择的 Aone 应用名
  • 客户端密钥在最下方的配置 tab，可切换预发/正式环境，不同环境的密钥不同
  • 注：如果你需要先在本地开发验证，可以点击 编辑 将 预发环境 的回调地址改为 localhost 进行测试
