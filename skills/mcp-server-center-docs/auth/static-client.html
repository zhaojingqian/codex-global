静态客户端接入指南

作者: 飞超 · 更新时间: 2026-04-07

基础信息

  • Aone MCP 网关域名：
    • 线上环境：https://mcp.alibaba-inc.com
    • 日常环境：http://mcp.taobao.net
    • 预发环境：https://pre-mcp.alibaba-inc.com
  • OAuth 元信息地址：https://mcp.alibaba-inc.com/.well-known/oauth-authorization-server
  • 相关协议
    • OAuth2.1 协议：https://datatracker.ietf.org/doc/html/draft-ietf-oauth-v2-1-12#section-1
    • MCP 授权协议：https://modelcontextprotocol.io/specification/2025-03-26/basic/authorization

概览

  • 你的系统或应用需要先完成 OAuth 客户端注册，我们将为 MCP 客户端颁发 client_id 和 client_secret
  • Aone MCP 网关支持标准的、基于授权码模式的 OAuth2 授权流程
    • 你可以通过日常环境的 小毛毛智能 了解和学习 OAuth2
    • OAuth2 是一个应用非常广泛的授权协议，你可以直接向大模型询问 "我该如果实现一个 OAuth2 客户端"
  • 对 OAuth2 和 MCP 客户端有一定了解后，按照本文介绍完成接下来的开发和对接工作

准备工作

前往 接入身份管理页面 -> MCP Client 管理页面，注册 MCP Client，获取 客户端编码 和 客户端密钥

操作流程文档 → MCP Client 注册流程

第一步：请求 code

在这一步中，你需要构造一个链接，并在用户浏览器中打开该链接。

用户打开该链接后，浏览器会自动跳转到对应的授权服务器（例如 BUC 集团登录）的认证或授权页面，用户在页面中确认授权后，会跳转回 MCP Client 的回调页面。

地址：

GET /oauth/authorize

参数：

参数 是否必填 说明
response_type 是 授权类型，需填写 "code"
client_id 是 客户端 ID
scope 是 授权作用域，填写 server:{name}，其中 name 为 MCP Server 的名称，例如 coop 。scope 的更多用法详见 OAuth 授权扩展
state 否 用于保持请求和回调的状态，授权成功后回传给 Client
建议每次都生成一个随机字符串
redirect_uri 否 客户端回调地址
如果不填写，则使用客户端注册时的默认回调地址
code_challenge public 客户端必填 详见 OAuth2.1
code_challenge_method 否 code_challenge 为空时，默认为空（为空表示不使用 PKCE）
code_challenge 非空时，默认为 plain
支持 S256 或 plain，详见 OAuth2.1
如果提供该值，则在获取 access_token 时需要提供 code_verifier

示例地址：

https://mcp.alibaba-inc.com/oauth/authorize?response_type=code&client_id=cat-ai&scope=server:coop&state=random_string

返回值：

根据不同的 MCP Server 的配置，重定向至相应的 授权服务器（例如 BUC OAuth2），用户登录 授权服务器 并完成身份认证，重定向至 MCP Client 回调地址并带上 code 和 state 参数。

客户端在本地或日常环境进行开发时，仍然可以使用 OAuth 正式环境：

在发起授权的时候，redirect_uri 传一个 127.0.0.1 的地址，这样授权完成后，会跳回 127.0.0.1 方便本地调试开发。

第二步：获取 access_token

在 MCP Client 的服务端调用以下接口，用上一步获取的 code 换取对应的 access_token。access_token 默认有效期为 30 天，30 天后需进行刷新，或重新授权。

请求：

POST /oauth/token HTTP/1.1
Host: mcp.alibaba-inc.com
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code
    &code=mcpc_FYh1vYzxk4RSgXX2E3mBVBJujjV9fiaf
    &client_id=client_id
    &client_secret=client_secret

# 注意参数放在 POST Body 中
# 上面的换行仅用于更好地在文档中展示参数，实际传参时不需要换行

参数：

参数 是否强制 说明
grant_type 是 授权类型，固定为 "authorization_code"
code 是 第一步获取的 code
client_id 是 客户端 ID
client_secret confidential 客户端必填 客户端密钥
code_verifier 前置步骤中提供 code_challenge 时必填 与 code_challenge 匹配的校验码，详见 OAuth2.1

默认成功返回示例：

{
  "access_token": "mcpa_LqjxkR0XjCZr8sjWlb2ydEOQ6MSGZfCg",
  "expires_in": 2592000,
  "refresh_token": "mcpr_FbrWyuOZjVYDXpdoKbGB3bnF3eU9qWV2",
  "scope": "server:coop",
  "token_type": "Bearer"
}

字段说明：

字段 说明
access_token访问令牌，以 mcpa_ 开头
expires_in访问令牌过期时间，单位(秒)
refresh_token刷新令牌，以 mcpr_ 开头
scope授权范围，格式为 server:{name}，表示该访问令牌可使用哪一个 MCP Server
token_type固定为 "Bearer"
通过该流程获取的 token 只能用于访问指定的 MCP Server。我们也提供了 "可访问多个 MCP Server" 的 token 生成方式，详见 OAuth 授权扩展

第三步：使用 access_token

获取到 access_token 后，在连接 MCP Server 或调用工具时，带上 access_token：

GET /coop/sse HTTP/1.1
Host: mcp.alibaba-inc.com
Authorization: Bearer mcpa_LqjxkR0XjCZr8sjWlb2ydEOQ6MSGZfCg
POST /coop/sse HTTP/1.1
Host: mcp.alibaba-inc.com
Authorization: Bearer mcpa_LqjxkR0XjCZr8sjWlb2ydEOQ6MSGZfCg
Content-Type: application/json

{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "query_recent_workitem",
    "arguments": {}
  }
}

其他接口

检视 access_token

POST /oauth/introspect HTTP/1.1
Host: mcp.alibaba-inc.com
Content-Type: application/x-www-form-urlencoded

token=mcpa_LqjxkR0XjCZr8sjWlb2ydEOQ6MSGZfCg

返回结果如下：

{
  "active": true,
  "scope": "server:coop",
  "client_id": "cat-ai",
  "username": "buc:feichao.sfc",
  "token_type": "Bearer",
  "expires_in": 3600,
  "empId": "177403"
}

其中 active 字段可判断当前 access_token 是否有效

刷新 access_token

  • access_token 默认有效期为 30 天，30 天后需进行刷新
  • 刷新后可得到一对新的 access_token/refresh_token
  • 刷新后，旧的 access_token 将在 10 分钟后自动失效，旧的 refresh_token 会立即失效

请求：

POST /oauth/token HTTP/1.1
Host: mcp.alibaba-inc.com
Content-Type: application/x-www-form-urlencoded

grant_type=refresh_token&refresh_token=mcpr_FYh1vYzxk4RSgXX2E3mBVBJujjV9fiaf

参数：

参数 强制 说明
grant_type是授权类型，固定为 "refresh_token"
refresh_token是刷新令牌，以 mcpr_ 开头

返回值参考上方「获取 access_token」接口

MCP 网关提供了批量刷新 token 的接口，适合客户端定期在后台调用。详见：OAuth 授权扩展

撤销 access_token

撤销一个 access_token，对应的 access_token/refresh_token 不能再使用。

请求：

POST /oauth/revoke HTTP/1.1
Host: mcp.alibaba-inc.com
Content-Type: application/x-www-form-urlencoded

token=mcpa_LqjxkR0XjCZr8sjWlb2ydEOQ6MSGZfCg

响应 HTTP 状态码 200 表示撤销成功，响应结果如下：

{ "revoked": true }

错误码

目前我们暂不提供错误码机制。

请求成功时，HTTP 响应码均为 200。

请求失败时，HTTP 响应码为 4xx，你可以将 response body 作为整个 "报错信息"。
