动态客户端使用指南

作者: 飞超 · 更新时间: 2026-04-09
更多 MCP Server 的使用方式 → 使用 MCP Server

介绍

Aone MCP 网关当前已支持 2025-06-18 版本 MCP 协议 授权流程。在 Cursor、Claude Code 等客户端中，直接使用 https://mcp.alibaba-inc.com/code/mcp 这样的地址即可进行连接，不再需要 secretKey 或其他形式身份凭证。

客户端将在合适时机发起 OAuth2.1 标准授权流程，用户完成授权后可使用该 MCP Server。

适用场景

  • For MCP Server 用户
    • 目前一些常见的编程软件已适配 2025-06-18 版本 MCP OAuth2.1 授权流程，例如 Cursor、Claude Code 等
    • 你可以直接在这些软件中进行使用，具体流程见本文下方
    • 如果你使用的编程软件不支持该授权，但是支持 Stdio 类型的 MCP Server，你可以通过 mcp-remote 进行接入，详见下方 使用 mcp-remote
  • For MCP Host/Client 开发者（或 Agent 开发者）
    • 如果你正在开发一个 MCP Client（例如一个内部 Agent），并期望对接 Aone MCP 的 OAuth 能力，考虑实现成本与复杂度，我们建议优先对接 静态客户端注册机制（而不是本文中的动态客户端注册机制）。
    • 当然，如果你正在实现一个通用的软件，期望按照统一的形式对接多种不同来源的 MCP Server，则建议基于 2025-06-18 版本 MCP OAuth2.1 来对接 Aone MCP。对接完成之后，请将你的动态客户端注册信息同步给我们，我们会基于该信息进行数据统计和流量分析。

使用常见编程软件

目前以下软件已支持 2025-06-18 版本 MCP OAuth2.1，下面简单介绍每个软件中的使用方式。

Cursor

打开 Cursor Settings，在左侧选择 "MCP"，点击 "New MCP Server" 按钮进入 mcp.json 的编辑器。

在 mcp.json 添加以下配置（如果已有 server，请注意 json 文件的格式）：

{
  "mcpServers": {
    "my-server": {
      "url": "https://mcp.alibaba-inc.com/code/mcp"
    }
  }
}

当需要进行授权时，Cursor Settings 页面中会展示 "Needs authentication" 文案和 Connect 按钮，点击按钮即可触发授权。

Claude Code

在终端中，执行以下命令添加 MCP Server

claude mcp add --transport http code https://mcp.alibaba-inc.com/code/mcp

然后打开 claude，在 Claude TUI（Terminal User Interface）中输入 /mcp，进入 "Manage MCP servers" 视图。找到刚才添加的 Server，并进行 "Authenticate"。

MCP Inspector

Transport Type 选择 Streamable HTTP，在 URL 中输入 https://mcp.alibaba-inc.com/code/mcp，点击下方的 Connect 按钮即可触发授权流程。

使用 mcp-remote

Artlab 地址：https://artlab.alibaba-inc.com/npm/package/mcp-remote

mcp-remote 是一个 NPM 包，用于将远程 MCP Server 转换为 Stdio 类型，同时添加对 2025-06-18 版本 MCP OAuth2.1 的支持。通过 mcp-remote，你可以在任意支持 Stdio 类型的软件中对接 Aone MCP 的 OAuth2.1。mcp-remote 会通过本地文件缓存访问令牌，有效避免令牌泄露，同时提升授权体验。

你可以使用 npx（推荐用内部 tnpx 代替 npx）来运行 mcp-remote，其命令格式为 npx mcp-remote <remote-url>。

使用配置文件时，mcp.json 参考如下：

{
  "mcpServers": {
    "code-server": {
      "command": "npx",
      "args": [
        "mcp-remote",
        "https://mcp.alibaba-inc.com/code/mcp"
      ]
    }
  }
}

mcp-remote 遇到问题？

mcp-remote 依赖本地安装的 Node.js 和 npm，如遇到无法在浏览器中打开授权页面的问题，可以手动在命令行中执行：

npx mcp-remote https://mcp.alibaba-inc.com/code/mcp

查看命令是否正常执行。

授权信息缓存目录

mcp-remote 会将 token 信息保存在 ~/.mcp-auth 目录下，如遇到客户端失效、token 失效等问题，可以删除该目录并重启 MCP Server。

参考命令：rm -r ~/.mcp-auth/
