OAuth 授权扩展

作者: 飞超 · 更新时间: 2026-03-11

在 "一次授权一个 MCP Server 的基础上"，Aone MCP 网关提供了以下扩展接口，提供更加灵活授权方式。

批量授权扩展

通过扩展 scope 参数，支持一次授权申请多个 MCP Server 的权限。

请求 Code

授权链接中的 scope 支持填写多个 MCP Server 的名称，具体格式如下：

GET https://mcp.alibaba-inc.com/oauth/authorize
  ?response_type=code
  &client_id=aone-agent-server
  &state=aaaabbbb-aaaa-bbbb-aaaa-aaaabbbbcccc
  &batch=true
  &scope=server:coop server:o2 server:alinpm
  • batch 参数填写 true
  • scope 中填写多个 MCP Server 名称，注意前缀和空格分隔符，同时注意实际调用时需对参数进行编码

用户通过该链接完成授权流程后，浏览器会重定向至客户端回调页面。回调页面 URL 会有 batch=true 的查询参数，例如：

https://my-agent.alibaba-inc.com/oauth/callback?code=mcpc_xxx&state=aaaabbbb&batch=true

客户端使用该 code 参数调用下方的"批量获取 access_token" 接口，可获取到多个 token（每个 token 对应一个 server）。

获取 access_token

与标准的获取 access_token 接口类似，不过批量授权下接口路径为 /oauth/batch_token：

POST /oauth/batch_token HTTP/1.1
Host: mcp.alibaba-inc.com
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code
    &code=mcpc_FYh1vYzxk4RSgXX2E3mBVBJujjV9fiaf
    &client_id=client_id
    &client_secret=client_secret

# 注意参数放在 POST Body 中
# 上面的换行仅用于更好地在文档中展示参数，实际传参时不需要换行

默认成功返回示例（结果是一个 Map，每一个分割后的 scope 对应一个 token）：

{
  "server:coop": {
    "access_token": "mcpa_LqjxkR0XjCZr8sjWlb2ydEOQ6MSGZfCg",
    "expires_in": 2592000,
    "refresh_token": "mcpr_FbrWyuOZjVYDXpdoKbGB3bnF3eU9qWV2",
    "scope": "server:coop",
    "token_type": "Bearer"
  },
  "server:o2": {
    "access_token": "mcpa_LqjxkR0XjCZr8sjWlb2ydEOQ6MSGZfCg",
    "expires_in": 2592000,
    "refresh_token": "mcpr_FbrWyuOZjVYDXpdoKbGB3bnF3eU9qWV2",
    "scope": "server:o2",

}

其他实现细节

在批量授权的场景下，网关会基于一个 BUC Token（inner token）颁发多个 MCP Token，网关内部会负责维护两者之间的绑定关系。

通用授权扩展

一次授权可获取一个 "能够连接所有 MCP Server" 的令牌。采用通用授权时，客户端只需要为每个用户维护一个 token 即可。

请求 Code

授权链接中的 scope 填写 all_servers，例如：

GET https://mcp.alibaba-inc.com/oauth/authorize
  ?response_type=code
  &client_id=aone-agent-server
  &state=aaaabbbb-aaaa-bbbb-aaaa-aaaabbbbcccc
  &scope=all_servers

其余流程与标准 OAuth 授权相同。授权完成后，客户端可以通过获取到的 token 连接 Aone 开放平台上任意 MCP Server。

注意事项：

  • 在 2025年10月之前，我们有提供 scope 为 all_buc_based_servers 的用法
    • 使用该 scope 生成的 token 只能用于连接 "那些使用 BUC OAuth 的 MCP Server"
    • 如果你正在使用 all_buc_based_servers，你可以将它替换为 all_servers

批量刷新令牌

批量刷新令牌接口已于 2025-10-11 已下线。
