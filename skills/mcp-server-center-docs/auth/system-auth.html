系统间授权

作者: 飞超 · 更新时间: 2026-05-13
该文档仅针对 Aone MCP 网关上的 MCP Server。 zetta 网关的 MCP Server 请移步：HSF / HTTP 接口转 MCP【ZETTA】
新的系统间/应用级别的授权能力 正在设计中，当前请暂时不要使用本文中的授权方式。

1、MCP Server 负责人在选项中信任调用方身份

mcp.trust-caller-systems=app-1,app-2（支持填写多个 Aone 应用名称，多个名称用英文逗号分割）

2、调用方使用 Normandy Auth SDK 接入

接入文档：MCP 认证能力 Normandy Auth 解决方案

注意，生成 ClientMcpRequestAuth 对象的时候，相关参数填写规则如下：

val mcpServerUrl = "https://mcp.alibaba-inc.com/code/mcp"
val mcpRequestAuth: ClientMcpRequestAuth = ClientMcpRequestAuth.of(
    /* mcpServerUrl */ mcpServerUrl, // MCP Server 连接地址，不用带 url 参数
    /* aiAgentId    */ null,         // 固定填写 null
    /* bucUserId    */ "177403",     // BUC 工号
)
