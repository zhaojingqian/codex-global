解除 MCP 单次工具调用 60 秒的限制

作者: 飞超 · 更新时间: 2025-12-29
先说结论："超时时间" 与整个调用链路上所有节点都有关，Aone 侧仅能保证 "网关自身支持 60s 以上超时时间"，无法保证调用链路上其他节点不会超时。

为什么会有 60秒超时的限制？

默认情况下，Aone 应用（包括 Aone FaaS 应用）使用统一接入（或 VIP 接入），如果单个请求 60 秒没有响应（流式场景下 60 秒没有增量数据），统一接入会自动断开连接，导致 MCP 工具调用出错。

详见：https://aliyuque.antfin.com/mcnz0z/zu2lyi/gdrq6q

解决方案

目前比较稳定的链路是 通过 Java SDK 接入 MCP 网关，因为该链路底层使用 HSF 对接、且 HSF 不限制超时时间。其他的调用链路目前不做保证。

MCP 网关具体实现

对于客户端调用某个工具的 POST 请求，MCP 网关采用流式响应，每隔一段时间输出 "Waiting for tool to complete"，使得在每个 60秒时间窗口内总是有新增内容，如下图：

同时网关新增 mcp.tool-call-timeout 的选项，允许 MCP Server 开发者自定义超时时间。

操作手册

调整客户端超时时间

大部分客户端可以设置工具调用的超时时间，注意进行调整。

MCP Inspector 配置方法

在 MCP Inspector 的 Settings 中，将 Request Timeout 设置为更大的值（例如 600000ms）。

Node.js SDK 中的 Client 配置方法

在创建 Client 实例时，通过 requestTimeout 参数设置超时时间。

调整 MCP Server 在网关上的超时时间配置

前往你的 MCP Server 设置页面，在选项中添加 mcp.tool-call-timeout=600s。

如果你正在使用 Aone FaaS 应用，继续在选项中添加 http.use-faas-vipserver=true

注意预发和线上环境需要分别配置。

调整 Java SDK 接入配置或 Node.js FaaS 配置

Java SDK 接入

设置 HSF 的超时时间

# 10 分钟
mcp.hsf.server.timeout=600000

Aone FaaS（Node.js）接入

  • 修改 FaaS 源码中的超时配置
    • TypeScript SDK 中 server.callTool() 默认超时时间为 60秒，需要换成更大的值
await server.callTool(body, { timeout: 60000 }) // 此处的 timeout 需要改为更大的值
  • 修改函数配置中的线上超时时间（这个配置仅针对线上环境有效，预发环境为固定值）
