2025-08 MCP Server 域名校验

作者: 飞超 · 更新时间: 2026-03-20

变动内容

从 2025-08 开始，MCP 网关将逐步添加对 MCP Server 的域名校验，避免服务端 SSRF 攻击，新接入的 MCP Server 可能会遇到以下报错：

"MCP Server 对应域名（xxx.alibaba-inc.com）不在白名单内，请联系 Aone 开放平台管理员"

或

"SSE 地址指向的 xxx 域名不在白名单内，请联系 Aone 开放平台管理员"

处理方式

请直接联系 @史飞超(飞超)，将 MCP Server 详情页面地址 发给他加白处理。

注意：

  • 线上环境不接受加白 预发域名（更不接受日常域名）
  • 请确认你有的域名的所有权/使用权
    • 例如：你是域名归属应用的 owner 或 AppOps
