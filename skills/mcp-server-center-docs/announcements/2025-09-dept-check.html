2025-09 MCP 工具调用时启用部门校验

作者: 飞超 · 更新时间: 2025-12-08

变动内容

从 2025-09-11 晚（周四晚） 开始，Aone MCP 网关将开启对 "开放部门" 的强校验。开发者设置 MCP Server 的公开范围后，将决定：

  • 哪些用户可以在开放市场上看到这个 Server
  • 哪些用户有权限调用该 Server 中的工具

当用户的部门范围不匹配时，会出现 "当前用户不在该 MCP Server 的公开范围内" 的报错提示。

处理方式

调整部门范围

前往 MCP Server 设置，调整 "公开范围"：

如果当前选择了 "私有：仅平台关联的部门可见"，则需要在 "平台设置 —— 绑定部门" 页面中进行修改。

单个添加白名单

或是在选项中，通过 mcp.allow-user-list 将指定用户或部门账号的 工号 加入白名单：

注意事项

  • 修改配置后，不影响当前活跃的 MCP 会话。客户端需要重连一次，新的配置才会生效。
  • "单个添加白名单" 需要在预发和线上环境分别进行配置
  • 仍有问题的，请联系 Aone 开放平台管理员
