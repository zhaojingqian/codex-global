使用 MCP Server

作者: 飞超 · 更新时间: 2026-01-25

Aone MCP 提供标准的 SSE Transport 和 Streamable HTTP Transport 连接地址，用户可以在任意支持 MCP 协议的客户端中进行使用，例如 Cursor、Aone Copilot、Claude Code 等。

获取 MCP 连接地址

打开 MCP Server 详情页，例如 https://open.aone.alibaba-inc.com/mcp/server/yuque，获取连接地址：

说明：

  • 线上域名为 mcp.alibaba-inc.com，预发域名为 pre-mcp.alibaba-inc.com，可在页面中进行切换
  • 详情页默认提供 Streamable HTTP Transport 地址，例如 https://mcp.alibaba-inc.com/yuque/mcp
    • 你可以手动将 /mcp 后缀改为 /sse，以获取 SSE Transport 地址，例如 https://mcp.alibaba-inc.com/yuque/sse
  • 连接 MCP Server 时，网关会进行鉴权，用户需要进行 OAuth 授权，或是提供代码平台 Private Token（具体方式取决于客户端支持程度），详见 MCP 身份认证概览

在客户端中使用 MCP Server

一键安装到客户端

在 MCP Server 详情页右侧，我们提供了 "添加到客户端" 的快捷方式，点击图标即可安装到相应客户端（或是复制安装命令）。

在 Aone Copilot 中使用

如下图，打开 IDE 配置：Tools > Aone Copilot > MCP Servers

添加新的 MCP Server，Type 选择 sse，Server URL 填写 Aone MCP 提供的 SSE 连接地址。

在 Cursor 中使用

打开 Cursor Settings > Tools & MCP：

按下面的格式配置 MCP 地址：

{
  "mcpServers": {
    "code": {
      "url": "https://mcp.alibaba-inc.com/code/mcp"
    }
  }
}

在 ideaLab 中使用

在 Authorization Token 中填入个人 Private Token。

Private Token 可在以下页面获取：https://code.alibaba-inc.com/profile/account

在代码中使用 MCP Server

前往 https://github.com/modelcontextprotocol，找到你正在使用的编程语言的 SDK，并安装到你的项目中。

常用 MCP SDK：

  • Java SDK：https://github.com/modelcontextprotocol/java-sdk
    • 要求 Java 17+
  • TypeScript SDK：https://github.com/modelcontextprotocol/typescript-sdk
  • Python SDK：https://github.com/modelcontextprotocol/python-sdk
